# 私有 ACT 远程工作台

## 目标与已确认范围

用户要求将刚建立的 Rudra DINOv3 ACT 工作台发布为 Codex Sites 站点，
能够从另一台电脑访问。用户明确选择完整功能：启动/停止训练、运行推理，
以及现有数据浏览、仿真/回放画面、参数、视频导出。

本机入口保持 `http://127.0.0.1:8774/`；现有 ACT PID 339022、
Diffusion PID 322477 及 8773 工作台不因本次建设而重启、停止或调整。
不执行正式推理、导出视频或训练启停来验证站点；写操作用隔离测试服务验证。

## 方案及边界

选用私有 Sites 前端 + 云端 HTTP 桥接队列 + 本机主动出站代理。
Sites Worker 不能承载 MuJoCo、GPU 和现有 Python 进程，故不搬迁计算后端。
单纯上传静态 HTML 无法使用本机 API；公开端口/匿名隧道不符合默认私有站点要求。
保留现有页面、控件和 API 语义，仅增加网络桥接、连接状态及远程刷新节流。

访问使用 Sites 自带的账号登录，默认仅当前用户。站点私有范围不为桥接而扩大。
本机不监听公网端口；代理只访问固定的本机 8774 和此站点 origin。
关闭浏览器或离开 Codex 不应停止代理；本机关机/网络断开时网页明确显示离线，
不把缓存旧值标成实时。不承诺本机重启后自动恢复凭据或训练。

## 数据与请求流程

1. Sites 服务端保存原工作台页面；页面相对 API 地址仍为同源路径。
2. Worker 对 API 请求创建有截止时间的随机 request ID，放入 D1 队列。
3. 本机代理通过 Sites 支持的服务访问定期领取请求，只转发白名单内的
   工作台 HTTP 路径/方法，禁止任意目标地址、shell 执行和通用文件服务。
4. 普通 JSON/图片响应写回队列，云端返回原 HTTP 状态、必要内容类型和响应体。
   只读 GET 可做短暂缓存和合并；启动/停止、配置变更、删除等请求不可缓存或重放。
5. 视频等大文件通过 R2 流式传输，浏览器保留原下载/导出流程；不批量上传示教。
   超过平台单次上传大小上限的文件给出明确失败，不返回截断文件。

新站点副本仅为远程访问使用，不修改本机工作台源码或运行配置。
当前页面只含 `top/wrist` 两路原生 640×480 观测；数据源仍是本机既有数据集。
不把原始数据集、模型、凭据或日志目录作为源码发布。

## 一次执行与离线保护

代理只有一个实例，使用本机文件锁。云端请求领取采用数据库原子状态转换。
每个写请求在本地 SQLite 中先记录 executing，再调用一次本机 API，最后记录响应。
响应上传失败只重传响应，不重新执行命令。
若代理在执行与确认之间退出，恢复时将结果标为未知并要求查看本机作业状态，
不会自动重试写操作。只读请求可以重新获取。

离线时禁用新写操作并返回清楚的服务不可用信息。请求一旦超过截止时间，
代理不得在恢复连接后执行；站点不积压将来突然运行的控制命令。
代理有状态上报，网页独立显示“本机连接”和“训练指标更新时间”。
ACT 每100步输出指标，约一分钟；不能把这个正常间隔误判为桥接离线。

## 凭据与部署

使用本私有站点的服务访问凭据；Git 源码凭据仅交给 Sites helper 的 stdin。
凭据不写入仓库、前端、命令行参数、日志或普通配置文件。
本机服务凭据通过仅本用户可访问的一次性 Unix socket 注入进程内存，
注入后关闭/移除 socket。代理独立运行，使用很小的 CPU/RAM 预算，不加载 Torch。
部署用 Sites 私有发布工具；完成后提供平台实际返回的正式 URL。

## 实施留给工程实现的选择

可自行确定视觉细节、缓存 TTL、轮询频率、队列/响应清理上限和普通超时时间，
保持请求有界、低资源、写操作不会重复执行。使用无构建依赖的 Worker ESM，
D1 存请求状态，R2 存大响应；SQL 迁移随源码发布。

## 验收

- 单元和集成测试覆盖路由白名单、请求超时、原子领取、写操作去重、
  中断后的未知结果、JSON/图片/视频响应及异常状态。
- 本机假后端验证一次远程“启动/停止/推理”只执行一次，不调用真实训练写接口。
- 私有站点部署成功；用平台服务访问完成真实只读健康、训练进度、图像读取，
  并在登录的浏览器中看到现有工作台和当前训练曲线。
- 原 ACT 与 Diffusion 进程继续运行，源工作台文件/配置未更改。
- 提供站点 URL、本机代理位置及恢复/停止桥接说明；停止桥接不停止训练。
