# Ubuntu 实现交接：单次训练的分阶段步骤与验收

更新：2026-10-26，Asia/Singapore。本文是待实现的工程顺序，不代表已有训练入口、兼容数据、已训练模型或通过结果。

架构与概率细节参考[主计划](occlusion-aware-world-model-plan.md)和[数据流审计](world-model-dataflow-and-paper-audit.md)。本文件优先澄清实现顺序、已有数据复用和阶段门槛；旧计划中“先新采120条”的数量安排不再直接执行。

## 共同边界

- **只完整训练一次**，固定一个随机种子作记录；不增加多seed、模型组、LSTM比较或额外完整pilot训练。
- 已确认的新事实仅为：**Ubuntu 上已有300条双机位 A* 成功演示**。目标N分布、分辨率、采样频率、标定、控制版本及高频字段均待实际盘点，不预设“每N50条”或数据已兼容。
- 既有300条优先审查复用。`D0`取实际兼容、分区合法且经阶段2首次因果启动审核通过的专家训练集合；不默认截成120条，也不默认全部重采。失败/不兼容记录列清具体原因与仍可复用阶段。
- 主线固定为：显式实例/几何/384维ROI观测 → 七节点概率GNN＋GRU → 联合对象belief → 小型集合encoder＋MLP/GMM actor。DINOv3骨干始终固定，实例/几何任务头按阶段训练；不加载ACT、不生成未来RGB或新ROI。
- 0.2秒一宏步；actor输出并执行5×4命令，底层25Hz动作与100Hz控制；WM预测20个10ms子步。真实采集直接执行actor样本，候选搜索只用于最终baseline推理。
- 模型输入只用因果观测/历史与软件可读控制状态；GT只作既定监督/裁判。R4仿真GT裁判保留，真机停止与安全接口不是本轮必达。
- 下述产物名称表示**待生成的交接约定**，不是声称当前仓库已有对应脚本或结果。每阶段输出输入manifest、配套版本、指标、通过/失败原因和实际成本。

## 阶段0：工程接口与资源预检，可与只读盘点并行

- **输入：** 当前代码、配置和原始数据格式说明；可先与阶段1并行只读盘点已有资料，不要求写完新模型才能读数据。训练或新采集使用前完成接口契约，不假定旧记录满足新schema。
- **实现：** 同一执行器服务专家、在线采集和两种部署；五步从第0条执行，不沿用旧chunk均值融合/有效窗口。IK异常使用scratch状态或完整恢复，不污染环境。
- **字段：** 分开`U_pi/U_cmd`、绝对参考`U_ref`、100Hz应用记录`C_applied`和13D实测`R=(q,dq,f_z)`；记录原生dq、单位、有效前缀、实际Δt及terminated/truncated。
- **控制状态：** 保存插入本段U之前的`C_ctrl_start`，含参考锚、保持/导纳/限速/LPF及已有队列；不能经该字段把本段后缀动作泄漏给早期预测。
- **相机：** 每路保存camera_id、原始分辨率、K/畸变处理、外参/手眼、capture/arrival/decision-cutoff及预处理版本；不能混用scene_cam和实际两机位。
- **通过：** 时钟/五步执行、IK异常恢复、字段拒缺、动作前缀因果与输入白名单检查全部通过；3070Ti 8GB可完成分块前向及一次必要更新，报告实测显存/吞吐/存储。
- **失败：** 先修接口或资源配置，不启动完整训练；短检查中的实际优化/交互进入对应预算，不另起一套完整pilot训练。

## 阶段1：盘点已有300条，按真实能力复用

- **输入：** Ubuntu 上实际的300条双机位 A* 成功演示及其原始元数据/配置；文件路径与内容以现场盘点为准。
- **逐项审核：** N与布局分布、RGB原生尺寸/时间轴、0/.2/.4启动记录、相机标定、动作请求与控制参考、13D原生高频R、对象/可见mask/事件标签、控制器版本、终止语义和数据完整性。
- **分阶段判定：** 先固定源库存，分别输出前端、最小启动链、完整WM、BC的用途候选清单；这些是兼容性候选，不代表正式BC D0已获启动准入。缺高频动力学字段的图像仍可能用于视觉，不能因此把整份资料一概丢弃，也不能默认足够BC/WM。
- **分区：** 工程默认按episode/layout组尽量分层为train/calib-fit/dev约80/10/10，组不可跨区；实际计数由manifest给出，不写死各区条数。最终测试另保留120个未见任务场景，不从训练成功记录挑选。
- **D0候选：** 固定源库存、布局分区、用途候选和可核对的决策窗口，记录每N覆盖，不伪造均衡配额。正式D0仍须阶段2的固定初始front/启动链快照按Q21因果审核；旧“每N20条共120条”仅为历史采集起点，不作为截断或重采指令。
- **通过：** 每个计划复用字段可追溯到真实来源，候选manifest/缺口明确且分区无重叠。前端初始化训练前冻结来源、分区与用途；候选池不混称正式BC D0，后续首次启动准入有明确记录，不按模型表现静默换用途或换样。
- **失败：** 优先查原始高频记录/标定来源；仅在原状态、模型和执行器版本可验证时重放并重新记录，明确标为再生成数据并计成本。不能填零、复制低频帧、用低频差分冒充原生dq；无法恢复则阻止受影响阶段，不默认重采全部300条。

## 阶段2：监督训练视觉前端与最小启动链

- **训练：** DINO patch特征上的实例mask/类别与几何任务头；同时训练使三帧启动可运行的q0、关联/权重及两段保持转移。完整清扫动力学留到阶段3。
- **固定：** DINOv3骨干、ROI通道/标准化与公开几何目录；actor和critic不参与。GT可作标签，不能填入运行belief。
- **输入/输出：** 阶段1已固定的前端/启动用途候选池中的训练RGB、合法可见标签、标定及启动序列 → 两路白名单实例观测、几何/ROI与因果启动B/h；该初始化池尚不是已准入BC D0。以可得真实观测更新，不先用未来帧平滑当前状态。
- **预算：** 初始前端/启动训练最多100个等效epoch，每5轮做离线dev验收，首次达标保存配套快照。这是本轮新增**工程默认**，不是用户原先确认的论文参数；1轮按相应训练manifest的有效样本呈现数定义并记录。
- **质量门槛：** 平面映射P95≤2mm；可见比例≥50%的分桶实例precision/recall均≥95%；XY中位≤3mm、P95≤8mm。重遮挡单列，不能删困难帧凑门槛。
- **启动门槛：** 部署原位保持，在任务t=0/.2/.4采三对RGB；末帧支持全部六件，每件另有较早时刻支持；h0=0后顺序热身，.4秒不再清零。每次启动有可追溯pass/fail，不要求假装所有场景都能通过。
- **产出/失败：** 前端/启动链通过dev验收后，固定并保存完整初始front/观测误差/启动模块/标定快照；按Q21只用截至0.4秒的观测因果审核D0候选，输出首次正式通过/拒绝名单与原因，再冻结正式D0。此次通过/拒绝是首次准入，不是R5后续换版重筛；之后不因新模型质量波动静默换D0。未达标停在本阶段诊断，不用GT补齐，也不自动延长100轮预算。

## 阶段3：监督预训练完整世界模型

- **训练：** 七节点概率GNN、共享GRU记忆、轨迹分布、q0/q_end/关联、观测误差及必要事件预测；同一模型从阶段2继续，不另造对照网络。
- **固定：** 本轮前端/ROI版本；actor不训练。critic仅常规初始化私有encoder、value输出置零/slow复制，不用专家动作或奖励预训练critic。即时reward为解析函数，无reward网络。
- **输入/目标：** 当前版本从reset因果重建的B/h、13D机器人量、C_ctrl与U_cmd → 20子步联合分布；对象GT/实测R是监督目标。仅既定事件条件项允许限定轨迹teacher，GT不进入root/filter/actor。
- **目标边界：** 逐0.2秒概率监督、条件桥/提议/观测损失与GRU连续段训练；不增加跨宏开环训练loss。离散索引stop-gradient，学习段内保留连续路径/GRU梯度；reset前缀可no_grad burn-in。
- **预算：** 最多100个等效epoch，每5轮离线dev检查，首次达标保存初始WM包；这是新增工程默认。等效轮次按有效转移目标数累计，不把burn-in或新采集混作相同单位。
- **通过：** 概率归一化、p/q/条件桥、前缀因果、身份/祖先一致性、终止/短截断与权重数值检查全通过；在独立运动/接触及遮挡片段上，0.2秒与1秒位置预测优于静止/匀速动态参照，并报告NLL、覆盖、ESS和重现关联表现。
- **比较标准：** 静止/匀速是解析参照，不另训练baseline网络；以预固定dev片段和同一动作序列比较，不回填中间真实观测，不用只含静止帧的平均误差掩盖失败。
- **失败：** 不以loss下降代替模型可用；支持耗尽、非有限概率或不优于动态参照时先诊断，不进入想象策略训练、不增ensemble/新模型组或自动追加数据。

## 阶段4：固定初始表示，只给同一actor做BC暖启动

- **训练/固定：** 只更新actor私有belief集合encoder＋MLP＋整段GMM；暂固定配套前端/WM/filter及统计，critic不训练。
- **输入/标签：** 实际D0从reset因果重编码所得B/h、P、C_ctrl、N → 专家同域U_cmd；不接原RGB ACT，不读对象GT/私有ID/未来帧。
- **预算：** 正常完成100个等效epoch；令L为实际D0合法决策窗口总数，1轮为累计L次样本呈现，完整段和合法短尾均按窗口计，记录实际梯度步数和各N抽样量。
- **损失：** 完整五步用整段GMM NLL；专家有效短尾用同一GMM的前缀边缘NLL，不补未发动作。先检查标签在有界策略支持内，不裁剪越界标签伪造有限loss。
- **一次准入：** 只用100轮终点完整配套快照；每N10场共60场，按部署随机采样完整执行，无搜索/教师救场；启动失败计分母。等权宏平均≥20%，即至少12次成功；逐N报告，允许个别N为零。
- **产出/失败：** 通过后得到π0及配套初始化包；该60场复用为0新增步记录，不额外跑30场。未达12/60报告诊断，不自动续训、补采、换seed或重测；不把仅BC模型当最终WAM结果。

## 阶段5：同一actor进入单次在线MBRL

- **采集：** π0先完成首个正常MuJoCo回合；每.2秒直接采一段五步命令，经共同执行器执行，不做候选评分/重采。新增实际交互总计最多30,000宏步，失败和启动保持也记账。
- **回合内：** 前端、WM、actor、critic权重/统计保持同版；B/h、控制状态与模板随实际历史更新。
- **回合末依次更新：** 真实训练图像监督任务头 → 固定新front并重算所用回放、从reset重建B/h/模板 → 同版误差拟合/WM监督 → fresh想象actor–critic → 下回合启用配套版本。
- **策略学习：** 当前actor连续调用五次，每次只输出实际会执行的.2秒chunk；隐藏生成场景产生转移/低维观测，filter形成下一完整belief。actor只通过REINFORCE及既定熵/尺度处理更新；不加持续BC或行为KL，不反传更新WM。
- **critic：** 想象λ-return为主，既定实际replay辅助仅取新增actor交互的真实奖励；不把专家D0奖励混入，空新增池跳过。D0仍用于感知/WM监督和想象根，D0/新增起点按既定1:1采样，空池有明确处理。
- **边界：** 真terminal尾值0；可控truncation在完整宏边界，意外短前缀不造h_end/bootstrap。已终止的生成根新增reward/PBRS/tail为0，保留外层零贡献，不重抽alive或用GT修复。
- **产出/停止：** 在5k/10k/20k跨点后的完整回合更新结束保存快照，30k硬截止按合法宏边界truncated后更新保存；记录实际步数，不为凑节点超预算。
- **失败：** 非有限loss/概率或非法输入停止受影响更新并诊断，实际已花费数据仍计费；技能退化如实记录，不自动恢复BC约束或增加训练分支。

## 阶段6：选定唯一完整模型，构建两种推理方式

- **选择：** 用direct在预定独立dev场景每N5场比较5k/10k/20k/30k完整快照；宏平均exact-N最高者入选，同分取较早。0步BC包不候选，须有实际想象actor更新记录。
- **冻结：** 同时固定front/WM/filter/actor/critic/slow-value/归一化与规则版本；不单独换头，不训练baseline BC或V_BC，不看最终测试或search优势反向选模。
- **direct：** 更新真实B/h后，actor采一个五步chunk直接执行；不调用未来rollout给本次动作择优。
- **search：** 同一actor采K=32首段，J=4外层观测分支、M=16内层belief、五宏步一秒预测；后四段仍由同一actor续写，以解析reward＋同一Vπ尾项选首段，每.2秒再决策。
- **通过：** 两种包装的参数/统计/规则哈希相同；固定根状态/样本时K=1执行与direct相同；影子状态/RNG不污染真实环境，评分不调用MuJoCo真实未来。
- **校验：** 一宏预测对齐同一实际首段；一秒离线诊断条件于相同记录动作，不把实际后续重规划改变动作的差值全归为WM误差。

## 阶段7：只评估，不再训练

- **输入：** 阶段6选定的冻结完整checkpoint；每N20个预固定未见任务场景，两种执行方式配对，共240回合。
- **任务规则：** 相同0/.2/.4启动、80秒硬截止、两秒确认/三秒早停和安全条件；启动失败保留分母，不换简单布局、不按结果筛场景。
- **记录：** 每N成功数/成功率、direct/search配对差值、失败类型、任务耗时/路径、感知/滤波/actor/search实际墙钟与峰值显存；明确这是本次训练结果，不声称跨训练稳定性。
- **完成标准：** 240次预定尝试全部有模型版本、场景、终止原因和指标记录；失败也是有效评估结果，不要求search必胜。测试数据不回流训练、噪声拟合或选模。
- **交付：** 唯一checkpoint、训练/数据manifest、阶段验收记录、240回合逐次结果及汇总、实际总成本。缺任一阶段则报告未完成与已完成范围，不编造结果。

## 预算、状态与真机范围

- 初始前端/启动和完整WM各“最多100轮、每5轮离线检查、首次达标”是新增工程默认；BC“100轮终点只一次60场准入”是既定协议，两者不能混用。
- 准入60场＋四节点dev共120场＋最终240场，共420个验证/测试回合；满80秒上界560分钟任务内模拟，加新增训练100分钟共660分钟。既有300条采集成本另列；reset、校准与优化/推理墙钟另计，早停会缩短。
- 训练需保留可重编码的原分辨率图像并压缩分块读取，实际分辨率/容量由阶段1确认；不能把既有低分辨率图上采样后声称新原生数据。8GB按分块视觉和低维FP32实现，资源默认不等于已验收。
- 真机不是本轮必达。保留robot/TCP/手眼/FT来源和时钟接口；GT停止裁判、仿真mask/状态标签不能直接迁移。以后先验证冻结checkpoint的输入/执行/停止接口，再另定硬件继续学习的合法监督。
- 必须修接口/数值错误才能前进；常规可逆参数用工程默认并记录，不为本交接增加多seed、ACT、未来RGB、ensemble或额外完整训练。
