## 1. 已确认的研究设计

| 项目 | 决定 |
|---|---|
| 任务 | 初始六件零件，目标 N=1…6；任意身份的恰好 N 件完整进入；单次连续清扫，无第二次恢复清扫 |
| 控制范围 | 从固定复位姿态开始，覆盖接近、建立接触和清扫；保留现有底层控制与安全停机 |
| 专家/部署执行 | Q20选A：新D0专家只负责高层选路，命令经过与两组部署相同的力觉接触锁存、接触保持、限速、Z导纳及失联/安全执行链 |
| 输入 | 顶部/全局和腕部两路 RGB，可标定；显式实例分割、几何观测、ROI 特征 |
| 视觉骨干与任务头 | R5选A：DINOv3骨干始终固定，不用ResNet；实例分割及几何decoder/任务头在训练期间持续监督更新，回合内固定版本；最终两部署使用同一完整冻结checkpoint |
| 多视图融合 | 保留各路来源、时间戳、相机位姿，在同一个 belief 更新器中联合关联；单路可见也有效，不重复计数 |
| 图结构 | 六个零件节点＋一个聚合机器人/刷头节点；零件—零件及机器人—零件双向交互；桌面、托盘为几何上下文 |
| 动力学 | 带循环记忆的概率 GNN；每 0.2 秒输出机器人和六件零件共 20 个 10 ms 子步的联合轨迹；场景级 GMM 的模式贯穿整段，模式内采用 AR(1) 时间相关 Gaussian 残差 |
| 创新相关结构 | Q24选A：机器人(q_i,dq_i)、零件(x,v_x)/(y,v_y)/适用的(θ,ω)各用2×2Gaussian创新块，f_z单独；不同块/对象间创新独立，不强制积分一致 |
| 动作前缀因果 | Q25选A：第j个10ms prior点仅依赖root/h_t和u_1…u_ceil(j/4)；全段共享模式权重/AR系数只依赖root与u_1，含full-U的h_end不广播到早期输出 |
| 必要终止事件 | Q27选A：先采连续Gaussian轨迹，再按时间前缀预测跌落阈值/非刷头不安全接触等必要事件；交统一规则决定τ/c，不反向重解码本宏μ/Σ，不新增非平面即失败 |
| 事件配对监督 | Q30选A：实际有效C与E联合密度；仅事件条件头训练可读既定对象GT轨迹＋实测R，root/连续prior/filter/actor不变；想象/搜索用生成C，不重复加完整轨迹NLL |
| 训练身份对应 | Q32选A：历史/祖先链一致整段绑定，合法歧义排列在联合密度内求和；C/类别/几何/fallen同π，机器人R不排列，不逐帧换绑、不用GT对应纠正运行状态 |
| WM训练跨度 | Q33选A：逐0.2秒宏转移的20点轨迹/事件联合监督，GRU跨连续段训练；0.4…1秒开环只验证，无跨宏辅助loss；不取消一秒搜索或想象actor–critic |
| 非终止支持状态 | Q28选A：首版无独立flat/tilted等物理支持模式；准平面状态/h/场景GMM保留，非终止倾斜/翻滚不删对象、不筛测试或另判失败，单独报告误差 |
| 记忆 | 每个联合场景假设内，每个对象分别维护 h；循环单元共享参数，值不共享；状态、关联和记忆一起重采样 |
| 隐含物理因素 | 不增加显式质量/摩擦后验，先让 h 从历史学习综合影响；不声称识别出准确物理参数 |
| belief | 少量带权联合场景假设，每份覆盖全部六件；同时保留运动和观测—记忆关联的歧义 |
| belief 纠正 | 使用观测引导提议分布，再做概率权重修正；不能校正了位置却仍沿用不适用的 bootstrap 权重 |
| 轨迹提议 | 网络提议末状态，再按同一 prior 的条件 Gaussian mixture 抽取中段；不是直线插值，不读取中途零件 GT |
| 启动 | reset 姿态保持 0.4 秒，t=0/0.2/0.4 各采一对 RGB；末帧观测齐六件，每件还须有一个较早时刻支持；失败计入测试分母 |
| 记忆次序 | h0=0；先由旧状态和已发动作更新一次 h，再形成 prior、接入新观测做 posterior；0.4 秒结束不重置 h |
| 机器人观测纠正 | 对联合轨迹 GMM 以实际连续机器人测量做解析条件化；模式重加权，并将机器人测量的父假设边缘似然计入粒子权重 |
| 力觉范围 | **Q19选B：** 仅预测并条件化未裁剪、未滤波的Z通道，按已知复位基线作有符号校零；其他五轴不进入两组真实/想象actor、critic、filter或动力学输入，可后台记录 |
| 状态监督 | GT作训练标签/评估；Q30明确仅事件条件项训练可读既定对象GT连续轨迹＋实测R，root/h、actor/critic/filter/连续prior不因该例外读取对象真值 |
| 机器人未来状态 | 学习闭环响应，可借助指令/IK 基准；由预测关节状态和已知运动学计算 TCP、腕部相机与连杆姿态 |
| 机器人概率字段 | Q23选A：每100 Hz子步R_j=(q_1…q_6,dq_1…dq_6,f_z)，13维；dq为原生瞬时速度，不用角度差分代替；宏步20子步共260个连续标量，actor动作仍5×4 |
| 想象观测 | 模拟几何、可见性、漏检和噪声，再经同一 belief 更新器；不生成未来 RGB，不生成新的 ROI |
| ROI 记忆 | 真实帧使用 ROI；想象帧的新 ROI 标为缺失，历史外观记忆继续保留；训练包含连续缺 ROI 的序列 |
| ROI 坐标 | 固定 DINOv3-S/16 实例池化的 384 维特征和固定标准化；取消独立可训练的 128 维 ROI projector |
| filter 观测白名单 | 几何估计、离散类别、相机/时间元数据、固定 ROI 及可用性；原始 mask/框/confidence/soft 类别概率不额外送入 filter |
| 几何观测误差 | Q29选A：不增前端逐实例协方差字段；观测模型从候选状态/相机/预测遮挡/旧历史给偏差及正定协方差，可异方差，生成与likelihood同源并独立校准 |
| 提议网络训练 | Q37选A：q0以既定初始状态/静态类别标签、q_end以连续末状态标签训练归一化密度；合法绑定与责任聚合，GT仅目标端，q_end保持parent的静态类别 |
| 静态几何来源 | Q31选A：公开类别规格目录＋已知统一size_scale；实例类别由RGB/历史推断、保留不确定性，分支查几何/半径；无本回合真类/真半径输入、不自由估实例尺寸 |
| actor | 两组使用同一个最终MBRL actor及参数：belief集合编码器＋MLP＋GMM随机chunk；每次chunk采样只采一个整段模式 |
| 时序 | 底层动作 25 Hz；每段五步、0.2 秒，全部执行后重新决策；模型步长 0.2 秒，预测五步、共 1 秒 |
| 策略训练 | R6-D：同一belief-MLP/GMM先在D0因果推断输入上做BC，得到π0；R7-B/R8-A/R9-B：每N10场共60场，六种N等权宏平均任务成功率至少20%（成功至少12次）才进入MBRL，暖启动设成本上限，未达标报告诊断、不自动加数据；随后fresh想象REINFORCE＋critic。无独立baseline策略训练；R11-A只做初始BC，MBRL不加持续BC/行为KL |
| 价值训练 | Q35选B：唯一critic以当前actor想象λ-return为主，另加真实replay奖励＋该actor想象bootstrap辅助；仅更新critic及自有encoder，不更新WM/filter/actor；最终同一V_π供baseline搜索尾项，偏策略近似须校验 |
| 真实价值辅助来源 | Q36选A：仅WAM新增合法决策交互，成功/失败都保留，不混专家D0；无新增有效记录时跳过辅助，D0其他用途不变 |
| 初始数据启动 | R13：优先审核Ubuntu现有300条双机位A*源记录，固定分区与用途候选；Q21先候选、后用初始可用snapshot因果准入保留。正式D0按兼容性/分区/初次启动审核确定，不再强制每N20条；R5换版不重筛 |
| 最终D0重编码（历史） | 原Q22选A针对事后baseline BC，已由R1取代；不再执行该独立重编码/BC阶段。固定D0的既定模型训练用途及正式测试启动门控保留，不以全D0启动通过约束选模 |
| 即时奖励 | Q26选A：每条模型生成隐藏转移的摘要按既定公式解析算分，再求外层期望；删除reward网络/损失，critic仍学习长期回报，actor/critic仍只读belief |
| 奖励输入编码 | 起点与有效终点的潜势所需状态＋目标/事件历史/时长摘要；不额外编码全部20子步；完整轨迹仍供动力学与统一事件规则使用 |
| 世界模型对照 | 同一最终完整checkpoint用于两种部署；WM*动力学/filter/观测模型/必要事件预测及统计、固定奖励/终止规则完全相同，无独立学习式reward模型 |
| 学习调度 | R5：DINO固定，任务头回合末用实际训练RGB/标签更新；同版重算观测/重建belief与模板、更新观测误差及WM/actor–critic后，下回合启用配套版本；最终两组不再训练/各自适配 |
| 最终版本选择 | Q34沿用A并按R1修订：本次训练以实验组direct执行的独立验证六种N宏平均exact-N成功率选完整快照；同分较早、启动失败计分母，0步用于初始BC准入/诊断，不作最终候选；不以测试/搜索baseline差距选模，全部成本照计 |
| 执行方式 | 实验组：actor直接采一个五步chunk执行；baseline：同一actor采K个首段，经同一WM预测、解析奖励及同一V_π尾项选最高分；两组每0.2秒更新真实belief后再决策 |

### 两组的当前定义与共同控制条件

研究问题：对完全相同的最终MBRL模型和策略，推理时增加世界模型候选搜索，相比actor直接出动作，如何改变exact-N成功率、任务效率和在线计算成本？这是在线规划开/关比较，不是BC与MBRL策略训练比较。

| 项目 | baseline：同一MBRL模型＋在线搜索 | 实验组：同一MBRL actor直接执行 |
|---|---|---|
| 视觉前端 | 同一最终DINOv3＋已持续学习的分割/几何任务头及统计，最终评估冻结 | 完全相同 |
| 状态估计与世界模型 | 同一最终WM*，运行时正常预测和更新belief/h | 完全相同；直接执行仍需WM维护当前belief |
| actor与训练数据 | 唯一训练所得MBRL actor、相同D0/新增回放及最终参数 | 同一个actor及全部参数，无第二套训练 |
| 想象中的策略改进 | 共同actor已接受REINFORCE＋critic更新 | 完全相同 |
| 候选生成与续写 | 同一actor采K个首段，各首段后用该actor续写四段 | 只采一个五步chunk，不做候选未来续写 |
| 评分与执行 | 预测一秒、解析奖励＋共同V_π尾项，选最高分首段执行 | 直接执行所采chunk，不调用critic给动作选优 |
| critic | 直接复用唯一训练所得V_π，不另训V_BC | checkpoint中保留同一个critic，直接出动作时不调用其评分 |

本次训练只训练一个最终checkpoint，再评估上述两种部署，不增加第三组或恢复四格。正式评估期间两组全部权重/统计固定，测试数据不回流训练，belief/h在各自回合正常更新。“共同状态估计”指同一历史用同一模型推断；两组执行不同动作后，历史和belief数值自然可能不同，不强行共享某一组的在线状态。

顺序明确为：完成唯一WAM数据采集与WM/actor/critic学习 → 按实验组direct独立验证选定并冻结完整checkpoint → 原样用于direct和K搜索两种部署 → 配对测试。取消最终WM*下重新编码D0、训练baseline BC和独立V_BC的阶段；不分配baseline新增训练采集，不因增加搜索而重新优化任何参数。

R2进一步规定训练采集与实验组部署都直接执行actor样本；WM仍用于当前belief的动作条件预测/观测纠正，真实交互后的模型监督与想象学习保留。K候选搜索只用于baseline最终独立评估；如另有独立搜索校验/资源日志，其转移和评分不回流训练，不用于采训练数据或选择checkpoint。旧搜索采集所造成的搜索行为偏差不再是本轮训练来源；不同历史actor版本的真实回放仍可能偏离当前策略，不能因此称Q35辅助严格on-policy。

共同完整checkpoint包括GNN轨迹动力学、GRU记忆参数、belief提议/更新器、观测误差模型、必要事件预测、MBRL actor、critic/slow-value及相关归一化/校准统计；同时固定奖励函数/潜势/终止规则及其版本，前端使用同一冻结快照。两组逐项校验参数/统计/规则哈希，而非仅声明结构相同。Q26已取消学习式即时reward头，没有独立决定主终止的continuation头。复制参数不复制某个回合的在线belief/h；每个评估回合从reset依据本组历史独立推断。

本比较只改变最终部署时是否增加候选搜索，训练成本共同计一次，再分别报告在线成本。两组都已受益于MBRL，baseline本身也是基于模型的规划，不能称其为“没有MBRL训练的策略”，也不能将差异解释为想象actor–critic训练的收益。选模以direct表现为准，具有对direct验证目标的选择偏向，须披露；不能依据搜索组差距反向挑checkpoint。

### 2.2.1 已确认的 reset 与热身

0.4秒保持计入80秒任务时间、实际交互和采集成本；学习策略和正式测试启动失败计入全部尝试/测试分母，不默默换布局。启动质量判定不等于状态精确已知。Q21已确认初始教师候选采集的bootstrap例外：先记录，模块可用后再审核正式D0，不声称当时已有在线门槛。原Q22针对最终baseline BC离线重编码的门槛例外已由R1取代，不再构成一个独立训练阶段；运行仍不允许数值非法belief或GT补齐。actor在0.4秒后开始决策，之前保持段仅用于观测/记忆热身和模型监督；BC只在0.4秒后的合法决策点计算动作损失；这不是延长任务时间或重置h。

### 2.3 观测引导提议、关联和权重

每个场景内为每路观测采用一份具体的一对一关联，允许未匹配/漏检/误检；同一对象可以得到两个相机的支持。跨场景保留不同关联。仅交换标签而不改变无序“状态＋记忆”集合的分支不算新信息。

首版把关联 A 明确作为联合目标变量。用归一化的联合测量模型 ℓ(Y,A | x,H_previous) 同时描述匹配、漏检和误检，不使用含义未定义的关联先验分数。权重为：

w_new ∝ w_parent × pθ(R_obs | parent,U) × pθ(X | R_obs,parent,U) × ℓ(Y,A | X_end,H_previous) / [q_A(A | Y,R_obs,parent,U) × q_X(X | A,Y,R_obs,parent,U)]。

这是非终止宏步接入真实或模拟机器人轨迹后的契约：先对joint-GMM以R_obs解析条件化、更新模式权重；**父假设边缘证据pθ(R_obs|parent,U)仍须保留。** R为Q23的20×13 q/dq/f_z轨迹；Q24已确定q/dq相关创新块，使用完整块结构轨迹密度，不按标量独立或独立逐帧密度计算。不能硬覆盖节点或漏掉父证据。原生dq不是角度差分，联合建模不天然重复；FK/TCP/相机和裁剪/滤波/latch等确定性派生量才不重复计证据。旧记录/执行器版本仍须审计。

X表示完整对象轨迹。Q28已取消首版独立非终止支持变量，不为它增加p/q因子。Q27附属终止E的当前filter目标不观测E、视觉likelihood不依赖E且不按存活筛选，Σ_E pη(E|C)=1，边缘化后不另乘事件概率；未来若增其他离散变量须另定义。末帧视觉因子只作用于末状态。**Q16已确认：末状态提议＋同prior条件Gaussian mixture补齐。** 写为q_X=q_end(X_end|A,Y,R,parent,U)×pθ(X_mid|X_end,R,parent,U)。当前vision/proprio目标与提议的中段条件因子相同，可抵消为：

w_new ∝ w_parent × pθ(R_obs|parent,U) × pθ(X_end|R_obs,parent,U) × ℓ(Y,A|X_end,H_previous) / [q_A × q_end]。

网络提出的是末状态分布；中段从 prior 条件分布抽样，不做直线插值。混合模式按 pθ(l|X_end,R_obs,parent,U) 抽取，不能沿用 q_end 的分量编号。仍保留父场景机器人证据、关联概率和末点混合密度比；不以“桥接抵消”为由删除这些因子。必要随机离散因子若未抵消，仍须计入。若增加独立中途事件测量，须重新加入对应因子并检验该化简，不能照搬端点公式。

具体工程默认如下，均属于近似传感器建模，不是像素观测的精确后验：

1. 每相机采用“各对象 Bernoulli 检测＋Poisson 杂波”的有限集合模型。给定 x/历史/相机，先以 pD_i 抽是否检测每个对象，得到 d 个对象检测；再从截断于 0…L−d 的 Poisson(λ) 抽杂波数，L=12。每相机关联必须一对一，null 可重复，未匹配检测是杂波。
2. 在有限集合测度下，联合测量密度为 exp(−λ)×Π_杂波[λc(y)]×Π_漏检(1−pD_i)×Π_匹配[pD_i g(y|x_i,H_previous)] / F_Poisson(L−d;λ)。分母依赖 A 的匹配数，不能省略。转成有序列表时只依赖本次检测总数的阶乘常数，对相对权重可统一抵消；绝对 NLL 的测度约定必须一致。这是有界近似传感器模型，不声称复现真实 NMS/top-12 的分布。
3. 两视角先在完整场景、相机与历史条件下使用条件独立近似；不声称误差自然独立。校准须检查共同偏差，协方差膨胀采用固定校准参数，不根据当前残差任意改 σ；相关性未完整建模需在结果中报告。
4. q_A 使用有放回 null、无放回检测的顺序采样。对象处理顺序由 parent/先验预测的 XY 确定；每步在剩余检测＋null 上归一化，取 softmax 与 5% 均匀分布的混合，保留全部合法匹配支持并记录实际条件概率之积。不能先硬 gating 删除匹配，再声称 full support；不用 Hungarian 分数代替采样概率。
5. q_end使用观测引导场景GMM并计算完整末状态混合密度，再用同prior条件桥补齐中段。Q28不另采非平面/支撑模式，不为其伪造离散概率；collection/partial等确定派生量不重复计概率。连续角度用展开坐标，观测朝向用归一化周期密度；样本不事后裁剪再套未裁剪密度。场景GMM分量、关联和必要事件仍按各自已定契约处理。

匹配观测因子分为g_geometry(y_g|x,κ,H_previous)×P(class_hat|y_g,x,κ,H_previous)×g_ROI(r|y_g,class_hat,x,κ,H_previous)。候选几何由静态κ查目录，class_hat是有误差的检测输出；混淆矩阵描述后者，不以class_hat直接覆盖κ。几何用正定Gaussian/周期密度；不能把前端softmax向量当categorical观测，Q15仍不将其作为proposal/记忆数值输入。q0内部输出类别提议概率不等于新增前端soft类别观测字段。

真实ROI先用上一时刻、按相机区分的历史模板作宽Gaussian外观测量，再更新权重/关联后以EMA=0.2更新模板；协方差由同前端版本的独立序列校准并加正定下限，无模板时用宽相机级全局先验，不按隐藏ID造唯一特征。**Q29已选A：** 几何偏差/正定协方差由候选状态、相机、预测遮挡和旧历史决定，可异方差；相同函数既生成模拟几何也计算其归一化likelihood，不新增前端Sigma观测/未来Sigma生成器。几何σ不读取当前残差、mask/confidence、同帧ROI或新观测先写入的h作捷径；当前ROI仍可走已定外观似然/提议路径。不能把σ(y_g)或σ(r)直接塞回对该观测的Gaussian而忽略归一化；也不以协方差膨胀掩盖系统偏差。

杂波密度 c(y) 同样是归一化模型：几何用覆盖工作区的宽 Gaussian、朝向用对应周期上的均匀分布、类别用 categorical、ROI 用宽全局 Gaussian；具体统计按相机/前端版本校准。想象 ROI 缺失时，匹配与杂波两侧的 ROI 因子都积分为 1，不采样未来 ROI，也不需要新增未来特征生成网络。前端变更后，模板、ROI 坐标系、协方差和杂波先验配套刷新。

以上借用标准多目标测量生成模型，只用来定义本计划的 likelihood，不把联合场景 SMC 改成 PMBM 滤波器。概率契约应测试条件采样的归一化及 p/q 一致性；校准模型仍可能有误，不以公式正确等同于真实环境后验准确。

当前观测不得先写入 h 再拿同一 h 给该观测打分。h 与对象状态、关联和整场景一起传递/重采样。全遮挡不等于对象消失；其他可见对象仍可能通过交互提供约束。

重采样工程默认：log权重归一化，ESS<M/2时整场景系统重采样，权重重置1/M，不再乘祖先旧权重。对象状态、静态κ/目录几何、h、模板、关联和假设内计时/事件标志一起传递；丢失的类别解释不会因此凭空恢复。旧ROI只作记忆，不重复当新测量降低不确定性。

本 filter 是**只按视觉和 proprioception 更新的近似 belief**。隐藏收集/成功等 GT 任务监控及“环境尚未停止”的选择证据不额外作为贝叶斯测量，不声称等于完整 POMDP 后验。由已条件化机器人轨迹和控制器上下文确定的 latch/计数不重复计似然。若未来加入独立的中途事件传感器，应增加相应因子，并重新核查 Q16 的抵消条件。

### 2.4 想象观测与动作

想象分支维护两个层次：模型抽样的隐藏场景，以及 actor 可读的完整 belief。隐藏场景经预测机器人姿态、双机位投影、简化遮挡几何和观测误差模型产生低维检测，去掉隐藏对象 ID 后送给同一更新器。actor/critic 不直接读取那一个隐藏场景作为已知真相。

新 ROI 缺失与检测缺失是两个标志。几何可用、ROI 缺失时仍做几何纠正；真实序列训练覆盖连续多步和整路 ROI 缺失。该简化会减少想象中的关联信息，须报告其分布差异。

每段先采样完整 20 子步隐藏轨迹，以已知规则推进事件、计时和终止。仅完整存活段生成下一次视觉观测，并把可测机器人轨迹交给内层 filter；任何真终止（包括 τ<0.2 秒或恰在段末终止）均保留有效前缀的奖励与实际 Δt，停止该分支，不补停止后的 R/图像、不再做下一次 posterior/actor 调用。完整宏步边界的外部截断仍按bootstrap规范处理；意外宏步中途非终止截断按§20处理，不使用含未执行后缀的h_end。内层假设不得由真实 GT 的任务状态补齐。

actor 每次输出 5×4 的固定桌面坐标增量 [dx,dy,dz,dyaw]；接触后 Z 沿用底层导纳的已知接管规则。预测条件仅包含段开始已知的五个有序命令、明确的可读控制状态C_ctrl及模式（含参考锚、接触保持/导纳/限速/LPF状态；定义见§20）。之后才得到的实际关节响应、执行掩码、中断时间及实际 Δt 是标签/结果记录，不能作为当时已知的未来预测条件。终止/安全中断可少于五步。使用有界动作分布并正确计算概率；不沿用旧 ACT 的历史 chunk 均值融合。

**R1最终部署：** 实验组由共同最终actor直接采一个五步chunk执行，不为动作选择调用未来rollout或critic。只有baseline在线搜索K个首段；每个首段之后，用同一个最终actor续写四段，再加同一个V_π尾项，续写经历模拟观测和belief更新。搜索预算K/J/H预先固定；两组都用同一M和WM维护真实belief，但不要求direct承担搜索计算。同一未来观测历史中的M个粒子组成完整belief，调用一次V_π(b)；不同未来观测历史产生不同belief，须对其回报与V_π(b)求外层期望。禁止把生成用的隐藏场景当成策略已知的单点belief，或用V(平均物理状态)代替上述期望。

baseline搜索的外层默认J=4个未来观测分支，内层仍为M=16个belief粒子。每个外层分支都复制完整根belief；只为生成模拟环境抽一个隐藏场景。初始隐藏场景若已按根权重抽样，外层取样本均值，不再次乘同一权重。K候选共用可对应的初始场景、过程/观测噪声和策略随机源，观测值仍随各自动作生成。唯一训练流程的想象学习沿用既定外层分支机制，不能因为direct评估不搜索就取消想象训练。

baseline候选评分J_k = Σ_j ω_j [Σ_(h=0…H−1) D_(k,j,h) r_hat_(k,j,h) + D_(k,j,H) V_π(b_(k,j,H))]；r_hat由生成摘要解析计算，V_π直接复用共同最终critic。D包含累计折扣和存活掩码，真终止后的尾项为零。若枚举隐藏场景，ω使用相应场景权重；若按权重采样，则ω=1/J。选argmax_k J_k的首段实际执行；预测后续段只用于评分，不整条开环执行。V_π评估actor续写而非未来再次搜索的精确价值，这是有限窗口的近似。

当前belief更新与未来候选rollout是同一个动作条件动力学的两种用途：前者结合已发动作和现在的真实观测，后者在影子分支里给定候选命令预测未来。RSSM类模型并非只能更新“现在”，可用imagine/img_step滚动预测；本项目的概率GNN同理。critic不是动力学预测器，只给rollout末端belief估计长期回报；直接对相同根belief调用V_π(b_root)所得值对候选相同，不能单独拿来排序。搜索分支的状态、计时、随机源与真实belief/环境隔离，评分完成后丢弃，不读取真实候选未来。

折扣索引固定为 D_0=1、D_(h+1)=D_h×γ(Δt_h)×c_h。第 h 段奖励乘 D_h，不预乘该段终止标志 c_h，以免抹掉终局奖励；c_h 只关闭后续奖励/尾值。外部截断按前述 bootstrap 口径处理。

8 GB调度采用分块更新：先做初始单帧任务头监督及held-out验收；R5后回合末先更新任务头，再释放图像梯度图，固定新前端版本重算所用回放观测，随后更新低维GNN/filter/actor–critic。初始及后续DINO前向始终no_grad，任务头保留自己的监督梯度；不将整段双路1280 RGB图留在显存中。仅同版本观测缓存可复用，最终完整checkpoint用于两部署，无独立baseline BC/value-only阶段。概率密度、log权重及循环隐藏状态保留FP32，不将视觉AMP直接套到重要性权重计算。ViT-S参数少不等于高分辨率attention在8 GB必然可用，峰值显存和吞吐仍须实测。

前端版本包含固定DINO/可更新decoder与heads、384维ROI池化规则和固定标准化、resize/crop预处理及标定。R5训练期间任务头可变，观测缓存须以完整前端版本为key，不能跨版本默认复用；最终两部署一致固定。即使DINO不变，mask变化也改变ROI池化值和误差分布。belief 编码器可以在下游学习自己的特征变换，不改变冻结的 ROI 坐标。每回合对象的 ROI 历史模板仍是运行状态，照常更新，不属于优化器参数。动态观测误差模型在 WAM 训练期间可用真实回放校准，随后以 WM* 的同一版本供两组使用；不能让 baseline 缺少最终校准。h/belief 还依赖世界模型、提议和关联版本。回放学习段从中途开始时，以当前模型无梯度重放从 reset 到起点的低维历史，再对学习段反传。不可将中途片段直接当成零记忆 reset；前缀重放耗时也需记录。任务头更新后，以该版原始RGB重算所用序列、从reset因果重建B/h/关联/ROI模板；不将旧h/模板接到新观测，也不把缺失ROI当有效零值。

前端训练 OOM 退让顺序：清除残留图像梯度图与并发 GPU 工作 → 双视角逐路处理、降低 decoder 候选/训练 ROI 数和通道规模 → 对可训练 decoder 使用 activation checkpoint → 输入降到 1024 并同步内参、重新检查感知质量。回合内固定版本推理仍OOM时也按空间规模/解码规模做有记录的调整，再验收；不退回 ResNet，不自动降回 320。原生数据保留。若低维学习 OOM，先减 batch，再考虑改变 belief 容量或预测长度。

数据流式读写，不将全集放入 RAM。双路 1280 RGB、5 Hz 的未压缩像素量约 176.95 GB/小时，实际 PNG 压缩率未知；先测存储速率、峰值 RAM、峰值显存和吞吐。主机 RAM、数据盘容量与 CUDA/算子兼容性仍待目标机器实际核对。ROI/实例 mask 不持久缓存全图浮点概率图，mask 用压缩表示。

## 4. 任务终止与奖励

### 4.1 已确认的公共终止协议

- 从复位控制开始，80 秒硬截止；25 Hz 最多 2,000 个底层命令时槽、400 个宏步，其中包括 0.4 秒启动保持；不能在热身后重新起算 80 秒。旧配置 45 秒/1,200 帧不用于新实验。
- 首次 c≥N 启动两秒计时，之后 c 降低也不重置；计时期间 actor 继续正常发动作。
- 首次完整入区后才启动三秒无新入区计时；每次 false→true 的完整入区事件更新最后入区时间。
- 两个计时器同一步满足时，目标确认计时优先。结束时必须恰好 N 件、无部分入区及其他失败；另报连续 exact-N 稳定性。
- 同刻优先级明确为：硬安全失败 > 在 80 秒前或同刻到期的两秒确认终检 > 80 秒超时 > 三秒停滞。两秒确认到期即按终检成功/失败结束。78 秒达到 N、80 秒确认通过可成功；79 秒达到 N 不会将截止延到 81 秒。浮点容差不增加一个动作步的宽限。
- 安全规则沿用：接触后的 20 N 法向力阈值及既有 dwell、100 ms 接触丢失、3 m 接触路径上限、机器人不安全碰撞和零件丢失等。不会因为取消/调整任务级计时而移除安全条件。
- 三秒停滞和 80 秒硬截止按本任务真终止处理；学习切片或外部预算截断单独标 truncated。GT 终止监控只决定公共环境结束/计分，不向 actor 暴露隐藏收集状态，也不借 GT 为 actor 生成动作。
- 真终止的尾值为零、终态Φ=0；在完整宏步边界且末状态/记忆合法的外部truncated保留shaped value bootstrap，不伪造失败或清零势函数。可控预算/教师截断放在宏步边界；意外中段记录中断只保留实际前缀的WM/BC监督，不伪造h_end/value起点，不把它当任务terminal强制零尾值；详见§20。

**已确认的预测终止主依据与Q27 A：** 先抽同一20点连续轨迹C=(X,R)，再预测无法直接从现有状态推导的必要终止事件E；联合分解为pθ(C|parent,U)×pη(E|C,parent,U)。每点事件头仅读C_≤j、root/h_t及已生效命令，不以full-U记忆或未来子步为旁路，不反向重解码本宏μ/Σ。首版缺失事件围绕每件z<table_top−0.03的跌落及场景级非刷头不安全接触；XY越界、入区/过收、超力/失联、计时等继续由现有轨迹和规则计算。翻转、暂时非平面或检测不到不自动等于跌落/失败。

统一RuleEvaluator消费轨迹/事件及历史，决定latch、计时、最早τ/c和有效前缀，再交Q26解析reward；不另抽主continuation，不重复生存概率。可用尚未停止条件下的首次事件hazard实现10ms概率，具体标注/监督/校准仍须规范。当前filter忽略存活选择证据，附属E边缘化，不按内层预测E删粒子/改权重；Q16桥不增GT事件测量。终止生成分支不补停止后观测/posterior。Q28不设独立非终止支持模式，观测误差仍须校验；不以事件头冒充完整高度/翻滚动力学。连续GNN仍可学习接触响应，抽样次序不等于宣称物理碰撞没有影响。

实际执行保持既有100 Hz安全/控制检查。预测10ms网格不等于1ms物理精确解，事件概率/时刻与稀有失败覆盖必须验证；标签歧义和新增采集计费不因增加事件头而自动解决。

### 4.2 奖励工程默认建议

以实际 Δt 计时，γ(Δt)=0.997^(Δt/0.2)：

r_base = −0.05×Δt +100×I(终局成功) −100×I(终局失败) −5×I(本回合首次过收)。

终局奖励只发一次；首次达到 N 不发成功奖励；多种失败原因不叠加多个 −100；首次过收附加惩罚不重复，也不据此修改已定的终止时机。首次过收标志和隐藏入区计时随各场景假设历史传递，reset 时清空；环境真值标志只用于标签与终止监控。掉落等既定硬失败进入失败终局。

令 k=max(N−c,0)，K 为未完整收集对象中距有效完整收集区最近的 k 件，D 为工作区对角线：

Φ(s)=2×[1−min(|N−c|/N,1)] − (1/N)Σ_(i∈K) min(d_i/D,1) −0.5×I(k>0)×g(s)×d_A/(1+d_A)。

d_i 使用按零件尺寸收缩后的完整进入区域；布局项除以固定 N。d_A 是 TCP 到多个刷头几何感知起始位姿的最小归一化距离。k=0 时布局/工具项都关闭；空候选集合直接返回有界的最差接近项，不计算无穷大比值。Φ 有界；真终止强制 Φ=0。

**Q31运行几何契约：** 各场景分支按其推断类别查询共同目录/scale，GNN几何、观测生成/likelihood、完整/部分入区、潜势及工具参考位姿使用同一分支的同一几何/nominal_radius。先逐分支计算非线性规则/奖励，再按既定权重求期望，不能先平均半径替代类别歧义。实际环境继续按真实几何计分；运行模型不从layout/index/seed读取真类/半径，不改变实际终检。两组目录/scale/推断规则同版本；错误类别或有限假设遗漏仍会导致预测偏差，须独立检验。

**已确认关闭时机：g(s)=I(尚未触发现有近桌力控接触锁存)。** 用户于 2026-10-25 澄清选择沿用现有控制器 latch；近桌面高度和法向力阈值触发后，本回合 g=0，不重新开启。该事件不要求已经触及零件，不能替换为仿真 GT 刷—零件接触标志。真实执行读取现有 latch，想象中由预测/模拟 proprioception 和同一控制规则推进。数量/布局项继续，关闭辅助项不禁止策略接近其他零件。

起始位姿候选默认按真实刷宽/刷深 0.14/0.008 m、−75°…75°（15°步长）及三个横向偏移构造，纵向留约 0.02 m 余量。检查完整刷头足迹、桌缘、工作区和托盘墙；局部首次接触须为所选 K 集合的非空子集，参考候选不同时触及 K 外或已收集件。这些条件只筛潜势的参考位姿，不构成 actor 的动作禁令或固定对象身份要求。不调用完整 A* 或 MuJoCo 轨迹验证。不得误用返回旧 0.052 m 宽度的 legacy helper。

r_shaped = r_base + γ(Δt)Φ(s_next) − Φ(s)。**Q26已确认A，Q35补充B：** 想象训练和候选评估在每条模型生成的起终点/事件/历史/Δt摘要上，直接调用同一个固定纯函数计算该奖励；删除即时reward网络及损失。实际环境按同一公式用实际状态/事件记录reward，供计分、Q35价值辅助标签及独立校验；GT对象状态仍只用于既定模型/事件监督和计分，不进入actor/critic特征或候选真实未来。实际reward进入训练目标不等于将它加入策略观测。共同critic V_π及baseline搜索尾值均使用这一shaped return，无独立V_BC。

**Q17保留逐分支口径、由Q26修订实现：** 每条模型生成隐藏转移分别解析算奖励，再与本分支后续回报/尾值一起求外层期望；不以平均布局代入exact-N/top-k/首次事件等非线性奖励，也不由完整belief直接输出共用平均奖励。actor/critic不因此获得隐藏生成场景或GT输入。已删除reward头的训练配对问题；动力学/事件概率监督仍须规范，不能把矛盾场景强制拉到同一GT。

**Q18已确认A：起终点＋规则事件/历史/时长摘要。** 输入覆盖起点/有效终点的六件布局、工具及两端潜势所需上下文，目标N、两端latch/相关历史，本段终检成功/失败、本回合首次过收是否在本段发生、实际Δt及真终止标志；工具/托盘几何使用已知公共上下文。摘要来自本分支预测轨迹和同一规则，不从候选真实未来GT填充。真终止时终态Φ=0，外部truncated保持原口径。Q26将摘要交给固定reward函数，不另设20子步奖励编码器或学习式reward近似器。

完整20子步仍用于动力学、入区/出区、首次过收、控制器与安全计时。中途多收又退出会改变事件摘要，不能仅凭两端计数抹掉。按当前奖励公式，给定正确状态/完整摘要即可确定标签；这不保证预测的摘要准确。若未来新增路径积分等奖励，应重新检查摘要充分性，不能声称当前编码覆盖任意新奖励。

按上述真实基础奖励，80秒成功轨迹的保守折扣回报下界约100×0.997^400−4−5=21.1>0，失败回报为负。这不保证近似动力学/事件/critic的候选排序。解析奖励只消除reward网络拟合误差，预测摘要错误仍会导致错误回报。PBRS的策略不变性依赖其条件，不能推广为整套学习系统的保证。

### 6.2 指标

- 主指标：exact-N成功数/成功率，分N报告同一训练checkpoint的direct/search配对差值；不要求跨训练seed稳定性统计。若报告测试场景区间，限定为该次训练下的场景不确定性，不把测试回合当独立训练重复。
- 效率：实际训练交互量、成功回合的任务时间/动作数、接触路径及计算量；失败率和失败耗时一起报告，避免只挑快的成功回合。
- 失败：初始化失败、多收、少收、部分入区、丢失、接触中断、超力、碰撞、停滞和超时；启动失败保留在主成功率分母，不能只评价成功启动回合。
- 预测：0.2…1 秒位置/速度误差、联合预测 NLL、概率覆盖/校准、计数与事件预测、观测后恢复误差和 ESS。
- 遮挡：按真实可见性和持续时间分桶，报告每桶样本量；各策略造成的遮挡不同，分桶主要是描述性分析，不能直接当同遮挡条件的因果证据。
- 系统：感知、belief、actor、搜索和训练分别记录耗时/峰值显存；共同训练成本计一次，分别报告direct与搜索每次决策实测墙钟及分位数、在线总成本。同步仿真等待计算，逻辑0.2秒不等于满足200 ms实时性；不将direct与baseline称为等在线计算预算。
- 单独校验预测摘要产生的奖励/事件误差与价值偏差；解析reward公式本身也须核对终止/折扣/有效前缀。模型预测分数高、代码测试通过或视频保存都不等于任务成功。

感知工程验收目标建议：独立标定平面映射 P95≤2 mm；可见比例≥50% 时分桶实例 precision/recall 目标≥95%；XY 中位≤3 mm、P95≤8 mm；重遮挡单列，不能靠删除困难帧达标。它们是初始工程门槛，须由实际图像检验，不是论文保证。

1. 概率契约：轨迹 GMM/AR(1) 联合密度、完整机器人轨迹条件化及父粒子边缘证据、关联采样概率、log 权重、ESS 和整场景重采样；状态/记忆不串对象或跨场景。验证 Q16 完整轨迹比与抵消后末点比一致、条件模式重权及条件桥抽样，不把小型代数示例当作模型实现验收。
2. 遮挡闭环：无检测是合法观测；ROI 缺失不等于对象不可见；重新出现不重复计数；等价编号置换不改变策略结果。
3. 因果输入：隐藏对象真值、模拟观测的生成 ID、未来真实机器人状态不能到达 actor/critic；训练标签与运行输入分开。
   运行观测、训练标签和私有裁判必须为独立结构；禁止整包复用旧ACT observation/environment_state。按capture/arrival/decision-cutoff时间戳检查因果性，训练重编码不用居中平滑或下一帧补当前输入。当前仿真GT停止裁判仍是迁移缺口，不将模型输入无GT扩大为整套执行无GT。

5. 终止边界：80秒/2,000个25 Hz命令时槽（含0.4秒启动）、首次入区后的三秒计时、非重置两秒计时及优先级、exact-N/partial和安全事件。
6. 学习/评估隔离及R1/R2：唯一训练流程的WM正常学习、actor接受想象RL；最终两组WM*/actor/critic/slow-value/前端/统计/规则哈希完全一致，不另训baseline BC/V。训练新增采集与direct评估在每个合法决策时刻均只采一个chunk；用mock/调用计数检验候选搜索入口、critic选优和择优重采从未触发，低层限速/Z接管/安全中断保持。baseline才在最终独立评估运行K候选搜索；搜索分支不改真实belief/环境/计时/随机源，独立校验记录也不回流训练/选模。固定相同根belief和actor样本时，K=1必须执行与direct相同的命令，影子rollout不能改变它。训练回合内版本一致、回合间换版；回合末fresh想象更新保留，不能将禁止采集时搜索误写成禁止想象学习。

   R6下BC与actor/value想象根使用合法决策mask：已结束0.4秒启动、采集/准入时曾通过因果门槛、未真终止、当前重编码belief有限合法。保持/启动失败段可训WM与热身，不能作为自由actor决策；不因当前模型质量分数下降悄悄删合法D0。实际value辅助还要求真实actor决策记录；完整宏步边界且状态/记忆合法的外部truncated末状态可bootstrap；意外短前缀没有partial-memory支持时不作自由actor/value根或真实value辅助target，仍可保留实际前缀WM/BC监督与成本。

- [DreamerV3](https://arxiv.org/html/2301.04104v2)：世界模型/当前actor/critic持续学习、想象回报、REINFORCE、λ-return和归一化的参考；标准推理从当前latent直接输出动作，不做K候选critic选优，但模型仍可在想象中滚动预测未来。原法不要求BC；本方案按R6利用专家D0初始化小actor及监督显式模型，属于示范辅助MBRL改造，数据前提并不相同。显式实例多假设/模拟检测纠正及两种部署均为项目改造。baseline复用训练时同类预测机制及同一critic尾项，解析reward替代Dreamer的学习reward头；不把整个系统称为原版Dreamer。
- [Structured World Belief](https://proceedings.mlr.press/v139/singh21a.html)：对象永久性、每对象记忆、联合场景粒子、观测引导提议、随机关联和重要性权重的参考；其 file-slot 匹配不是现成的严格一对一双相机实例匹配器。
- [SOLD](https://arxiv.org/html/2410.08822)：动作条件对象表示预测、latent 想象及表示持续适应的参考；预测 slot 不等于生成相机 ROI 测量，原法不执行本计划的模拟检测→belief 纠正。
- [Graph Networks as Learnable Physics Engines](https://arxiv.org/abs/1806.01242)、[GNS](https://proceedings.mlr.press/v119/sanchez-gonzalez20a.html)：图结构、关系消息、循环物理推断和滚动误差训练的参考；未证明七节点清扫配置已经有效。
- [PlaNet](https://arxiv.org/abs/1811.04551)：latent overshooting是额外多步训练目标的参考；其latent变分目标不是本项目显式轨迹/事件/排列联合NLL的现成替换，也不意味着只用逐宏监督就不能多宏预测。

- [Mask R-CNN](https://arxiv.org/abs/1703.06870)：实例 mask 和 ROI 任务设计的可选参考；若采用通用实例 heads，必须适配 DINOv3 空间特征，不使用 ResNet 骨干或旧 ResNet 模型配置。具体轻量 decoder/head 组合尚为工程候选。

- [How to Train Your Differentiable Filter，IV-B/D、VI-E、VIII-B](https://arxiv.org/html/2012.14313v2)：观测/过程噪声区分、图像相关异方差及遮挡/平面推送实验的参考。其sensor网络输出R不是本项目已实现的生成观测mark；该论文不直接证明Q29 A/B谁在本任务更好，也不替代DINO小目标校准。

## 11. R5已确认：固定DINO，实例分割与几何任务头持续学习

R5（2026-10-26，用户选A）取代“前端整体达标后永久冻结”。DINOv3骨干始终固定；轻量decoder、实例类别/mask及几何分支在初期和新增数据阶段持续监督学习；不新增可学习ROI projector或前端协方差mark，384维DINO通道、池化规则和固定训练标准化沿用。ROI数值仍随图像和预测mask变化，不把固定骨干误当固定观测分布。

回合间更新顺序明确为：

1. 使用配套Front_n/WM_n/actor_n/critic_n完成本回合；权重、观测坐标与控制器版本回合内一致。
2. 使用新增和旧训练分区的真实RGB及可见mask/类别/几何标签监督更新decoder/任务头，覆盖不同遮挡和视角，防止只拟合最新回合。DINO始终no_grad；本版首选仅前端自己的监督loss更新任务头，WM/actor/critic目标不反传任务头。
3. 固定本轮新Front_(n+1)，重算抽中回放序列及其reset前缀的实例观测/ROI；缓存以完整前端版本为key。从reset因果重建belief、h、关联和外观模板，不继承旧特征上的h/模板，也不要求每次重编码全集。
4. 用该版检测器实际输出—训练标签配对更新观测生成/likelihood的pD、几何bias/协方差、类别/ROI/杂波参数；以独立分区检查校准。校验/最终测试数据不进梯度或噪声拟合，同版函数用于想象生成与实际likelihood。
5. 固定本次前端表示，按新观测更新WM/filter，再开展fresh想象actor–critic更新；下回合启用一致的模块/统计版本。观测模型/WM改变后，策略想象起点也须按最终当前版本因果重建，不跨版本复用中间h；观测校准与状态重建可交替完成，但不得以旧误差模型/旧记忆长时间训练新表示上的策略。
6. 初始D0名单及其准入版本不因后续视觉更新反复重筛/补换；保持已有合法/有限belief与质量失败的区分，不GT补齐。当前stage无新增数据时沿既定D0空池逻辑。
7. 最终按既定验证选完整checkpoint，direct/search共用同一已学任务头、WM/actor/critic及统计，正式评估全部固定。不增加跨seed复用/重复训练分支。

输入白名单和无未来ROI方案不变：真实帧ROI来自当前预测mask，想象新ROI仍missing，保留历史模板/连续ROI dropout。mask即使只小幅改变，也可能改变池化外观和几何测量误差；持续学习不能代替held-out质量/校准。通道标准化暂保留固定训练统计；若将来改变预处理/标定/统计，必须作为新前端版本并共同重编码，不能在线偷改坐标。

这借鉴[DINOv3冻结骨干＋任务decoder](https://arxiv.org/html/2508.10104v1#S6.SS3.SSS2)与[SOLD新策略视觉分布适应](https://arxiv.org/html/2410.08822v2)的机制，具体回合换版/监督与概率belief组合是本项目设计。3070Ti 8GB上的头更新、重编码和reset前缀重放成本仍需pilot；本轮未训练感知或修改执行代码。

## 13. R6历史备选C：生成未来相机图像，继续调用ACT（未采用）

用户询问“能否通过belief以及其他信息恢复想象图像”。该路线在机制上可行，补足原A/B的选择范围，但**尚未确认采用或实现**；不自动取消R5、改写无未来ROI简化、加载旧ACT、变更H5/概率目标或增加预算。

基本链路是：从完整B_t按权抽取一个隐藏场景ξ_t → 用概率GNN和actor动作推进ξ_(t+1) → 结合预测机器人q/FK、相机标定与外观/背景条件生成两路相机RGB → 供下一次ACT调用及相应观测更新 → 继续同一条隐藏世界轨迹。隐藏场景跨宏连续推进，不能每步独立重抽造成对象瞬移。它生成一个可能的未来观测，不是把belief可逆解码成唯一真实未来；多个场景不能先平均坐标或平均图像，避免鬼影和虚构对象。

当前belief保留XY/平面角度/速度、推断类别/公开几何及h/历史ROI，但没有完整高度/倾斜、精细材质、光照和背景。384维DINO ROI也不保证可逆像素重建。渲染需要公共资产、当前/历史RGB估计的外观和背景、以及明确的准平面假设，或额外学习相应视觉变量；缺少的字段不能从本回合GT补齐。腕相机来自预测q和已知FK/手眼，全局相机用公共标定；双视角共享同一场景与一致外观，不各自独立编造对象。

候选生成器有：

- **几何渲染：** 公开零件/机器人/CAD与背景条件＋预测位姿→隔离场景的双RGB。可用MuJoCo图形模块，但它只将已预测状态画出；不得clone环境隐藏qpos/layout/随机外观并推进真实未来物理来替代GNN，也不消费运动学刷新时计算出的接触/传感答案。可先用于仿真重建验证，不要求可微render来计算REINFORCE。
- **学习式条件decoder：** 预测场景、相机/机器人、历史真实图像/外观记忆→未来RGB；需要新增真实回放监督、细小对象/接触边界、时序与双视角一致性验证。无需直接上大型扩散视频模型，但轻量decoder是否足够仍未验证。
- **未来ACT视觉tokens：** 若最终只为ACT补输入，也可直接预测其兼容encoder特征，节省像素生成/编码；这属于另一种对齐/观测模型，固定DINO ROI不等于原ACT完整空间tokens，不能直接替换。

若选C，必须另行闭合以下接口：

1. **合法观测与遮挡：** 未来RGB保留对应机械臂/刷头遮挡和正常相机视角。若给ACT额外无挡布局图，那是另一种belief可视化输入，部署也需提供，不可冒充实际相机观测。预测图不是读取真实未来；使用未来真实RGB/真实物理渲染结果才违反当前边界。
2. **ACT与filter同源：** 可将同一生成RGB送ACT及当前版本Front→Y→belief，这会重开“仅低维模拟观测/新ROI missing”的既定简化并增加DINO前向。或保留低维模拟器，但须有一致的联合观测定义，不能另生成一份互相矛盾的Y。RGB经过Front保证输入来源一致，仍不自动使已有解析低维likelihood成为新生成器的精确推前分布；概率目标/近似与校准须另验算。
3. **当前遮挡仍需记忆接口：** 原ACT若只看当前RGB，生成未来图像使训练rollout可继续，并不自动让实际执行actor直接读取完整belief或知道被挡对象的去向；历史/循环记忆/额外belief条件是否加入须另选。不能把belief重建的当前图像再当新真实测量，反复更新B来虚增置信度。
4. **其他ACT输入未补齐：** 旧双机位ACT还要求36维历史机器人量、六轴wrench及不同视觉骨干；生成RGB没有补全当前13维/Z-only模型未预测的其余五轴，也未授权恢复ResNet/其他字段。是否适配旧actor仍需选择，不能承诺图像一生成就完整保持旧函数。
5. **策略所需质量和算力：** 除像素指标，还比较相同合法机器人输入下ACT在真实/重建RGB的chunk、目标实例/遮挡/接触边界一致性和闭环行为。当前帧重建通过不等于未来预测/MBRL通过；小零件即使只错少量像素也可能改变动作。K/J/H多分支还要多次生成与编码双图，3070Ti 8GB及200ms性能无证据，需单列pilot。

直接论文参照：[IRIS（ICLR2023）Fig.1/§2.3](https://arxiv.org/html/2209.00588)用预测tokens解码图像后训练图像策略；[DIAMOND（NeurIPS2024）§3.2](https://arxiv.org/html/2405.12399)在生成图像中训练actor–critic，说明像素想象并非原理障碍。[G-SWM（ICML2020）§2/§3.3](https://proceedings.mlr.press/v119/lin20f.html)提供对象外观/位置/深度与context、GNN/RNN演化和图像合成的机制参照。[DreamerV3](https://arxiv.org/html/2301.04104v2)也有图像decoder，但原actor直接读取latent，并非每步decode后再喂视觉策略。这些论文不等于双机位ACT接触清扫或本项目显式belief→RGB组合已验证。

本节仅保留C的可能性与约束；R6已选D，C未采用。此前针对C的工程建议为先做“当前合法belief＋公开几何/实际历史外观→双图→现成ACT”的重建输入小验证，再决定是否采用C及是否扩充状态；它不是已经获准开展训练/改代码，也不把当前真值诊断结果当部署输入。


## 14. R6-D已确认：小型belief actor先BC暖启动，再MBRL

用户澄清：ACT不是刚需，任务范围有限，希望在新增在线学习前有一个较成型、具备一定成功率的actor，以减少探索数据需求。原计划的actor确为**belief集合编码器＋MLP＋GMM整段动作分布**，不是视觉ACT。BC是一种训练方式，可以用于初始化这同一个小网络，不意味着新增第二套大模型；“原始参数随机、先BC再RL”和“随机参数直接RL”是不同启动路线。

结构沿用：每份联合场景内先用共享对象MLP编码六件状态/κ/h，再做场景内非线性聚合；M份完整场景embedding按其权重集合汇总，拼接目标N、13维机器人量及允许控制/时间上下文，经MLP输出整段GMM。一次采样得到5×4命令，五步全执行。不能先平均对象位置/半径或把一份隐藏生成世界当策略已知真相；actor不需额外接收原始RGB，时间记忆来自上游belief/h。

**R6-D已确认（2026-10-26）：同型小actor的D0 BC初始化 → 独立基础能力检查 → 同一actor继续想象actor–critic与实际数据更新。** 本决定取代R3“随机actor直接MBRL/全程无BC”；ACT迁移与未来RGB生成未采用，不开展此前渲染pilot。R11-A已确认不持续加入BC辅助或行为KL；初始BC结束后actor按既定想象回报目标继续学习。

已定数据流是：

1. 用既定D0/候选有效记录及训练标签初始化前端、启动链和WM，使因果状态推断可运行，不要求WM完全收敛；D0仍须通过新schema和共同执行器语义审核。
2. 在一份匹配的初始front/WM快照下，从reset因果重放D0得到每个合法决策点的推断B/h；以该时刻专家实际下发的命令为标签，最小化GMM动作密度的负log likelihood，只更新actor私有集合encoder与动作头。完整段用五步标签；真终止/安全中断的短尾段只对实际有效前缀计算同一GMM的边缘密度，不补停止后命令，也不丢弃整条D0。启动保持不作为自由actor的动作标签。
3. 训练输入不用零件GT布局、未来帧或GT关联；GT仍只作既定模型/前端标签与教师选路。BC阶段暂固定该输入版本便于对齐，不等于后续永久冻结WM或R5任务头。

### 20.1 一条训练链与两种最终推理

Ubuntu现有300条源记录先审核/分区/按用途复用（缺口才定向处理） → 初始化配套前端与WM/filter/完整启动链并独立验收 → 用该初始版本因果审核实际D0 → 因果重编码D0 → 同一小actor做100等效epoch BC → 一次60场准入且至少12次成功 → 当前actor直接到MuJoCo采集、总新增最多30k宏步 → 回合末更新任务头、同版重编码/校准、监督WM、fresh想象actor–critic → 依预定direct验证选并冻结完整checkpoint → 在相同120个测试任务上分别direct/search，共240回合。0新增步只复用那一次60场准入，不额外跑30场。后续actor无持续BC/行为KL，D0的感知/WM监督及想象根用途保留。

真实执行依次为RGB/机器人测量/可读控制状态 → 前端 → belief/h → actor采样 → 共同执行器 → 实际响应 → 下一次观测。想象依次为从完整belief抽生成隐藏场景 → 同一actor出动作 → WM/控制规则推进 → 模拟低维观测 → 同一filter更新完整belief；生成场景只供观测/奖励/事件生成，不直接进入actor/critic。只有search在部署时展开多个候选；两种部署使用同一个actor/critic/WM及统计。

### 20.2 明确执行器状态与四层动作，避免训练目标错位

| 字段 | 定义与记录 | 训练/推理边界 |
|---|---|---|
| U_pi | actor在策略域采出的完整5×4有界chunk，保存动作界/变换和策略版本 | REINFORCE的logπ属于该样本；不是裁剪后的指令或实际TCP位移 |
| U_cmd | 进入共同执行器前的策略域请求；actor时等于U_pi，专家高层选路也生成同域请求 | 本文后续动力学条件U统一指这一层；D0初始BC标签也来自这一层，已发送/生效前缀另有mask |
| U_ref | 使用决策时参考锚累加增量得到的绝对参考序列 | 保存参考锚、目标、坐标/角度约定及时间；不假定锚等于FK(q)，不把它代入原策略logπ |
| C_applied、R | 共同控制器限速、保持、Z导纳/安全处理后的100Hz应用记录，与13D实测机器人响应 | 发生后作响应/监督；不能提前作为该段预测条件或冒充专家请求标签 |

C_ctrl必须点名可读的软件状态：末次应用参考(x,y,z,yaw)、接触保持锚/剩余时间、导纳/限速/LPF状态，以及会改变本段执行的已有队列/hold状态。C_ctrl_start在插入当前U_cmd之前快照，队列字段只含此前已提交的命令；本段full-U、后缀U_ref或其汇总不能经该字段绕过Q25前缀掩码。它与q/dq/f_z一起进入robot节点/允许上下文，真实记录、重放和想象均传递同一定义；由U_cmd和实际或生成R按共同软件规则推进。不新增13维机器人Gaussian的随机目标，也不假定能访问UR厂商闭环控制器的全部内部状态；未知执行影响仍由闭环响应模型近似并验证。C_ctrl不包含GT对象计数、隐藏任务计时器或私有接触答案。

旧[动作转换](../../sim/act/interface.py)第40–59行依赖start_reference，旧[执行器](../../sim/act/evaluate.py)第291–294、338–390、477行还使用参考锚、工作区裁剪、限速和接触/Z接管。必须保存上述分层，不能事后从多对一裁剪结果反推原采样。可逆tanh可按[SAC附录C](https://arxiv.org/html/1801.01290v2#A3)换元计密度；硬clip不适用同一公式，引用该密度机制不表示改用SAC。

先审核D0标签是否在策略分布支持内；tanh开放边界/越界标签不能硬clip后当原始连续NLL。真terminal截短转移时，完整U_pi仍可作宏动作的score-function样本；硬前缀因果使未执行后缀不影响回报，但可能增加方差。BC短尾因缺少专家标签使用前缀边缘NLL，与PG是否用完整已采动作是不同问题。不会为简化而将C_applied或实际位移塞进logπ。

### 20.3 两个必须补全的时间与吸收边界

1. **意外短truncated不伪造宏步末记忆。** 可控教师结束/训练预算截断安排在完整0.2秒宏步边界。真实任务/安全terminal依原协议尾值0；合法完整宏步的外部truncated仍bootstrap。若记录在宏步中途意外中断且非任务terminal，仅保留实际前缀的WM/BC监督，不用读全U的h_end冒充该时刻状态，不生成自由actor/value根或Q35真实辅助target；不把该未知尾值强制记0当成失败。未来如需这种bootstrap，才需显式partial-memory接口，目前不加新模块。
2. **已终止的生成根采用吸收态。** 因既定filter不使用存活选择证据，抽到的隐藏生成根可能按其自身已有计时/事件历史早已终止。仅当这些既有字段已足以判定时，令该生成分支τ=0、未来新增reward/PBRS=0、尾值0，不重复终局奖励、不继续动作/观测/转移；其零贡献仍按原权重计入外层期望与critic根目标，不删内层粒子、不重抽到alive或只对alive归一化，不用真实GT计时器修复。记录过期根质量；高占比表示该近似有问题，不声称此规则恢复完整POMDP后验。
3. **评分校验对齐动作。** 一宏预测对照同一实际首段；一秒开环诊断可使用保留序列中相同未来U_cmd，仅供离线模型检验且不回填中间观测/机器人/控制状态。search分数的后四段是裸actor续写，真实baseline却每0.2秒重搜，二者下一秒实际回报差含后续动作差异，不能全算成动力学/critic误差；不新增测试组。

[DreamerV3](https://arxiv.org/html/2301.04104v2)支持按已执行动作推进记忆和想象回报优化；[Gymnasium终止/截断说明](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)区分bootstrap资格。上面的partial-memory/多假设吸收根是本项目的实施补全，不是原论文已替我们解决的模块。

### 20.4 代码复用阻断与真机迁移前置条件

- **旧代码实施前必修：** 五步chunk与旧异步scheduler的0.2秒有效窗口冲突；IK异常路径可能遗留临时qpos；旧writer未记录完整13D/100Hz与相机元数据且可缺项补零；旧camera_pose/from_env绑定scene_cam不能混用overhead/wrist；专家与部署接触锁存尚须统一。以上为本轮静态重新核实的旧实现缺口，不代表新WAM已经运行出错。实施先统一同步executor、无副作用IK和schema，再复用到D0/采集/两部署。
- **型号和几何标定：** 数据/checkpoint记录robot_model、关节顺序/限位、TCP、出厂运动学校准、手眼、相机K/畸变/缩放裁剪及几何参考点版本。当前配置ur10_cb3_rudra不等于已核实现场UR10/UR10e型号；[UR官方校准说明](https://docs.universal-robots.com/Universal_Robots_ROS_Documentation/kilted/doc/ur_robot_driver/ur_calibration/doc/index.html)指出未使用出厂校准时末端位置可能差厘米。几何头和WM标签使用同一完整零件参考点，可见mask中心投桌面不能直接冒充它；首版通过几何/误差校准处理，不新增3D世界模型。
- **Z力通道：** 保留13D和Z-only设计，但记录FT来源、坐标/正号、payload/重力补偿、tare与内部滤波。仿真desired_force=1N、contact=0.20N、release=0.05N只是当前仿真参数；现场噪声/分辨力与传感来源未验证，不能原样当真机阈值。[UR RTDE](https://docs.universal-robots.com/tutorials/communication-protocol-tutorials/rtde-guide.html)的actual_TCP_force有payload补偿，[MuJoCo force](https://mujoco.readthedocs.io/en/stable/XMLreference.html#sensor-force)有其site/父子体定义，不能把两者当同一个未处理通道或重复补偿。
- **真机时间：** 记录capture/arrival/decision-cutoff/plan-ready/execution-start与计算期间实际hold/旧命令。执行前仅用已发生命令和已到达量测把belief推进到合法执行时刻，不能给旧根状态换新时间戳冒充补偿。RTDE可能跳包，配置频率不等于完整100Hz记录；缺测窗口处理与deadline/超时行为未实现时，不宣称真机0.2秒闭环可用。仿真暂停等待计算不能让真实桌面暂停。
- **任务停止与监督迁移：** R4的GT计数/两秒确认/三秒早停/部分安全裁判继续属于本轮仿真协议。真机StopSupervisor和全阶段可测保护仍缺；两RGB＋belief不保证恢复所有被挡计数或碰撞。R5/WM在仿真用的GT mask/状态标签也不会随checkpoint一起搬到现场。以后首轮迁移宜先冻结完整checkpoint验证推理接口；若要硬件继续监督学习，需另有合法标签来源，不默认照搬仿真训练循环，也不把真机验证升为本轮必达。

### 20.5 校准、资源与最小实现顺序

数据角色在manifest中区分：训练拟合、训练侧误差/噪声拟合、dev验收/选模、最终测试。用于拟合pD、bias、协方差、杂波等的“校准序列”属于训练侧拟合数据，不能同时冒充独立验收证据；dev/test不拟合检测器、噪声参数、归一化或其他权重。可在既定训练数据内划分用途，不自动追加新数据预算、不静默改正式D0名单及其BC用途；新front版本按R5同版重编码/更新误差模型后再做想象训练。

8GB上保持DINO no_grad、任务头和低维模型分阶段/分块更新；reset前缀可no_grad burn-in重建当前状态，选中的连续学习段保留GRU时序梯度，不每宏清零或全detach。分段梯度边界/长度记录为工程配置，不要求整个80秒RGB/循环图同时驻留显存；Q32祖先/身份绑定仍贯穿相应学习段。概率与log权重保持FP32，不能直接把视觉AMP套上去。

单次30k双路1280² RGB仅原始uint8像素约294.9GB，未含D0/标签/评估。训练图像须保留原始分辨率、可重编码并版本化，采用可恢复原始数据的压缩/分块与按需读取；评估冻结权重，优先低维日志/压缩视频并按需留原帧，不强制全部raw评估图常驻。不得为省显存静默降低分辨率/改变相机K或丢失精细零件信息。

| 已定部分 | 任务内模拟时间的上界（不含重置/计算） |
|---|---|
| MBRL新增训练30,000宏步 | 100分钟 |
| BC一次60场准入 | 80分钟 |

最小推进顺序保持简单：修共同执行器/IK与数据schema → 小样本核对动作密度、前缀因果、条件桥/序列责任及截断 → 同一次训练跑通感知/belief/BC准入/MBRL → 固定checkpoint做direct/search比较。现有独立序列同时用于必要的预测/校准验收，不增加模型组、多seed或额外完整训练。DINOv3、SWB、SOLD、Dreamer/MoDem各支持组成机制，不共同构成该组合的工程或真机成功证明；具体对照见配套审计。当前完成的是文档和源码静态复核，代码修复/训练/真机验证均未执行。

## 21. R13：Ubuntu现有300条示教优先复用与开发交接

用户确认Ubuntu上已有300条双机位A*成功示教；目录、每N数量、原生图像尺寸、时间轴、标定、控制器/模型版本及高频字段尚未检查。`D_source=300`只表示来源规模；`D0`是实际兼容、分区合法、通过初始因果准入的专家训练集合。旧“每N20条、共120条”的固定配额不再作为执行指令；不默认全300条兼容、截120条、追加重采或把其他分支的五机位数据当成本批。

先只读盘点并固定episode/layout分区、用途候选清单；可以并行实现公共schema/执行器。图像、BC、启动和完整WM分别判定资格：旧数据缺100Hz子步/原生dq，不妨碍有来源的RGB用于视觉，但不能冒充完整动力学监督。优先查同次原始日志与标定；可验证重录单列版本和成本，不把新GT拼入不一致旧RGB。成功-only数据的失败/稀有事件覆盖如实报告。前端/启动初始snapshot可用后，按Q21首次因果审核正式D0，之后按R5重编码而不静默重筛。

实际D0合法窗口数L确定BC等效epoch；100轮终点一次60场、至少12次成功的准入不变。后续同一actor只做一次、最多30k宏步MBRL，最终同checkpoint在120个任务上做direct/search共240回合；不恢复旧四格或独立baseline BC。

交接分支只发布文档背景，不含原始数据、权重或本地未提交控制器改动，不启动训练。Ubuntu先读[入口](ubuntu-wam-handoff.md)、[数据审核](ubuntu-dataset-compatibility.md)和[实现步骤](wam-implementation-stages.md)。这些文件区分已确认协议、新增工程默认与未验收事项；现有ACT训练CLI不能直接当新WAM训练入口。
