# Independent Hybrid A* → ACT · trial 4

本分支 `feat/hybrid-astar-act-trial4` 单独保存已使用的第四组 **Hybrid A*→ACT 原版**。
基于模拟器安全基线 `9102680d8e018b225ab34d36422572cd4b547166`，不包含 DINOv3、
残差强化学习或新的控制调参。它是后续视觉编码器改造的可追溯基线，不是新评测结果。

## 保留的接管规则

- A* 单次几何规划，负责接近和下降；实际距桌面 1 mm 时启用接触寻找导纳。
- 仅使用补偿、滤波后的腕部力反馈。0.5 N 持续 0.1 s 转维持阶段，
  0.8–1.2 N 持续 0.2 s 后 ACT 才接管 XY 与转角。
- 目标力 1 N，寻找 M/B/K＝10/400/10，维持 10/800/10；
  导纳和实际 Z 跟随补偿合成后的总修正限制为 ±2 mm。
- Z 持续由导纳与有界实际跟随补偿管理，**不执行 ACT 预测 Z**，不读取桌面接触力真值闭环。
- 首个有效 ACT 动作后 2 s，XY 加速度限制 50 mm/s²；转角加速度限制 0.5 rad/s²。
  之后精确恢复原生 ACT，不持续限制扫动加速度或每次查询重新缓启动。
- XY 速度上限 80 mm/s，转角速度上限 0.35 rad/s；导纳正常上抬/下探上限
  20/100 mm/s，进程内 IK 提前退出阈值 1e-6，安全保护不变。
- A* 前段、寻找接触与 ACT 共用 2000 个 25 Hz 动作帧；首次入区后的 2 s 终止窗口跨阶段连续。
  每布局仅一次几何方案、最多一次物理执行，不按失败重试、换 seed 或物理筛选择优。

ACT 仍是原 **ResNet18 视觉编码器**。原正式批次使用 step_100000；权重不随源码上传。
依赖目录中的 `3mm`／`5mm` 等名称来自历史试验链路，不代表正式第四组的最终参数；
最终配置以固定的 `control_profile.json` 和正式入口中的 PROFILE／TRIAL_SPEC 为准。

## 本次验证边界

15 个冻结运行源文件均与原 metadata 中的 SHA256 一致；模拟器基线的 67 个源文件
与原冻结指纹核对一致。两份原数值契约测试共 **39 passed**，覆盖交接限加速度、
2 s 后原生恢复、ACT 不夺取 Z、总修正边界和两阶段参数切换。
没有运行新的训练、物理推理或正式 120 布局评测，也不宣称全套测试通过或策略效果提升。

本分支不包含示教图像、checkpoint、评测 ledger、视频、数值轨迹或个人凭据；
旧结果、失败、模型和当前工作区的其他开发分支均未改写。
